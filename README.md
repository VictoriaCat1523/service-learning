ЗАБЫЛ НАПИСАТЬ В КОММИТЕ 16.10:

Чтобы узнать ID заявки, в F12 консоль открываем и пишем eventId
Дальше пишем const firstId = eventId
После октрываем следующий этап созданяи и пишем firstId == eventId, если все гуд, выведет true
В первый ввод, eventId выведет id заявки, которая не меняется до создания заявки
Возможно придется еще удалять папки с Id если чел передумает создавать, это надо будет решить
